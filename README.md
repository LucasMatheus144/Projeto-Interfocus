# Vendinha

</div>


<details>
<summary align="center">🧾 Resumo do Projeto</summary>
<br>

 Este projeto tem como objetivo **informatizar o controle de contas de clientes** (dívidas penduradas) de uma vendinha, substituindo o controle manual em papel por um sistema digital eficiente e moderno.

 A aplicação foi desenvolvida com foco em desempenho, organização e boas práticas, utilizando a seguinte stack:

- 💻 **Backend:** [.NET (C#)](https://dotnet.microsoft.com/) com suporte a **NHibernate** para mapeamento objeto-relacional.
- 🖥️ **Frontend:** [ReactJS](https://reactjs.org/) para construção de interfaces rápidas e responsivas.
- 🗄️ **Banco de Dados:** [PostgreSQL](https://www.postgresql.org/) como sistema de persistência relacional.

 O sistema visa facilitar o gerenciamento de clientes, dívidas e pagamentos, com foco em usabilidade, segurança e escalabilidade.

### 🌐 2. Frontend (React)

```bash
cd seu-repositorio/Projeto-Interfocus/VendinhaReact
npm i
npm run dev

```
> ⚠️ **IMPORTANTE:** Se a versão do npm estiver muito desatualizada, apenas rode o comando:
>
> ```bash
> npm install -g npm@latest
> ```
### 🔧 3. BackEnd

> 💡 **Dica:** Certifique-se de ter um banco de dados **PostgreSQL** rodando localmente antes de iniciar o backend.

---

### 📝 Etapas de configuração

#### 1. Abrindo o projeto
Abra o projeto no **Visual Studio**.

#### 2. Configurando a string de conexão
Vá até o arquivo:  
`Venda.API/appsettings.json`  
Substitua a `ConnectionString` pela sua string de conexão local do PostgreSQL.

---

### 🗄️ Preparando o banco de dados

#### 3. Executando os scripts
Abra seu gerenciador de banco de dados (como **pgAdmin**, **DBeaver** ou outro).  
Execute todos os comandos SQL contidos em:  
`Venda.DOMAIN/Schema.sql`  
Isso criará as **tabelas, triggers e views** necessárias.

---

### 🚀 Rodando a API

#### 4. Build do projeto
No terminal, vá até o diretório da API e execute:

```bash
cd seu-repositorio/Projeto-Interfocus/Venda.API
dotnet build
```


### ✅ 4. Finalizando

1. Após iniciar a API com `dotnet watch run`, será aberto automaticamente o **Swagger** no navegador, exibindo todas as rotas disponíveis da aplicação backend.

2. Ao rodar `npm run dev` no frontend, o console exibirá a seguinte URL: http://localhost:8081/
